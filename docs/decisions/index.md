# Decisions Index

本目录保存产品决策记录。产品决策记录用于解释长期有效的产品判断，并帮助后续版本理解为什么这样设计。

## 当前决策

- 当前暂无具体决策记录。
- 后续只有长期有效、需要解释原因的产品或工程判断，才新增 PDR。

## 命名

使用 PDR 编号加主题命名，例如 `PDR-0001-topic.md`。

## 模板

```text
# PDR-0001 Title

状态：accepted
日期：YYYY-MM-DD
关联版本：mvp

## 背景

## 决策

## 影响

## 关联
```

决策记录可以作为解释和约束背景，但具体实现仍以当前 active 版本包为准。
