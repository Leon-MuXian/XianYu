# Active Exec Plans

当前 active 目录用于存放正在执行、尚未完成的开发或文档任务。

## 当前状态

- `mvp-governance/`：阶段一技术基线已通过，等待真实 trial 阶段门，仍为 active。
- 产品范围、设计要求和工程映射仍以 active MVP 版本包、UI 原型和架构文档为准。
- 本目录不是产品规格、设计稿或工程映射本体。

## 重新拆解规则

- 新增任务应放在 `active/<task-id>/` 下，不再额外套产品目录。
- 任务文件应说明目标、范围、输入依据、交付物和检查方式。
- 新增任务必须能追溯到当前产品规格、设计稿、架构文档或明确的新增决策。
- 若任务输出改变产品、设计或架构要求，必须同步到正式版本包、设计稿或架构文档。
- 任务完成后，将任务移动到 `../completed/<task-id>/`，并标记完成状态。
