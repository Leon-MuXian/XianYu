# Completed Tasks

本目录只存放 `seren-meet` 已标记完成的任务，不存放调研、评审纪要、变更日志、验证报告或其他相关过程材料。

## 当前状态

- `admin-web-mvp/`：平台后台 WEB 端 MVP 开发任务，已完成。

## 存放规则

- 已完成任务应放在 `docs/exec-plans/completed/<task-id>/`。
- 每个任务目录应包含任务本体，例如 `task.md`。
- 任务本体应明确完成状态、完成时间、原始目标、实际交付物和验证方式。
- 过程性材料不进入 `completed/`；必要结论应同步到产品规格、设计稿、工程映射或决策记录。

## 非存放内容

- 不存放变更日志、评审纪要、验证报告等过程文件。
- 不存放尚未完成的 active 任务。
- 不存放未同步到正式文档的产品或工程要求。
